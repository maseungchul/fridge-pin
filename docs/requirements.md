# Fridge Pin 요구사항

## 프로젝트 개요

- 로그인이나 서버 없이 기기에 저장된 냉장고와 재료를 관리한다.
- 실제 냉장고 구조를 도면으로 표현해 재료의 위치와 유통기한을 쉽게 확인한다.

## 주요 기능

- **냉장고:** 냉장고 구조를 설정하고 등록·편집한다.
    - 냉장고 구조
        - 단 추가·삭제
        - 단별 도어 개수 설정
    - 본체
        - 보관 모드: 냉장·냉동
        - 본체 합치기·분리
        - 칸 개수: 최대 4칸
        - 각 칸의 좌우 분할 여부
    - 도어
        - 여는 방식: 왼쪽 열림·오른쪽 열림·서랍형
        - 도어포켓 사용 여부
        - 도어포켓 칸 개수: 최대 3칸
- **재료**: 위치별 재료를 등록·조회·수정·삭제·이동하고, 소비 완료한 재료를 확인하거나 복구한다.
- **장보기:** 구매 예정 품목을 관리하고 구매 완료한 품목을 선택해 냉장고 재료로 등록한다.
- **유통기한:** 도면에서 재료의 기한 상태를 확인하고 원하는 시점과 시각에 로컬 알림을 받는다.
- **설정:** 한국어·일본어와 시스템·라이트·다크 테마를 선택한다.

## 핵심 정책

- 냉장고, 재료와 장보기 데이터는 기기에 저장하며 앱을 다시 실행해도 유지한다.
- 도면 수정으로 보관 위치가 사라지는 재료는 저장 전에 개수를 안내하고, 확인하면 ‘위치 지정 필요’ 목록에 보관한다. 새 위치는 도면에서 지정하며, 저장한 도면 변경은 되돌릴 수 없다.
- 냉장고 삭제 시 등록된 재료도 함께 삭제하며, 소비 완료 기록과 장보기 목록은 보존한다.
- 저장이나 구조 변경이 실패해도 기존 데이터를 보존하고 다시 시도할 수 있어야 한다.
- 알림 권한을 허용하지 않아도 재료 관리 등 핵심 기능을 사용할 수 있다.

## 향후 검토

- 냉장고 추가 등록
- 영수증 인식과 구매 항목 등록
- 유통기한을 기준으로 한 장보기 자동 등록
- 기기 간 P2P 데이터 공유와 충돌 해결
- 암호화된 백업 파일의 내보내기·복원·병합
